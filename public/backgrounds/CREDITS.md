## Encoding

Scenery uses silent H.264 MP4, 960px width, 24fps, yuv420p, CRF 29, fast-start metadata. Each is a seven-second loop: source seconds 1–8, with the final second dissolved into source seconds 0–1, joining back to second 1. JPEG posters use the first frame of each finished loop. No audio is retained.
